UraxOS alpha for VirtualBox
1) Install VirtualBox: https://www.virtualbox.org/wiki/Downloads
2) Unzip UraxOS-alpha.zip.
3) Double-click "Create UraxOS VM.cmd" (creates the "UraxOS alpha" VM, EFI, 6 GB RAM, 4 CPUs).
4) Start "UraxOS alpha" in VirtualBox. It logs in by itself and opens Console Mode.
PS4 controller: plug it in by USB cable; a USB filter for Sony devices passes it to the VM.
Login (for sudo only): urax / urax
