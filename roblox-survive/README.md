# البقاء | SURVIVE (Roblox)

كود اللعبة كاملًا، يُرفع إلى Roblox عبر Open Cloud (بدون Studio).

- `shared/` وحدات مشتركة (الأغراض، المناطق، النصوص، الأصوات، المظهر).
- `server/` الخادم (البيانات، الغرف، العالم، المخلوقات، البقاء، الغنائم، إصلاح التضاريس).
- `client/` الواجهات والمؤثرات (اللوبي، العالم، الأيقونات، المؤثرات).
- `gen/` مولّد الخريطة: `common.lua` + `terrain.lua` (على دفعات)، ثم `structures.lua`، ثم `vegetation.lua`.
- `tools/deploy.py` يرفع الأكواد ويحفظ المكان، و`tools/rbx.py` يشغّل سكربت Luau عبر Open Cloud.
- `tests/` اختبارات تُشغَّل داخل Roblox قبل كل رفع.
- `art/` الأيقونة والصور المصغّرة ومصدر رسمها.

يتطلب مفتاح Open Cloud يُحقن في ترويسة `x-api-key` (لا يُحفظ في المستودع).
